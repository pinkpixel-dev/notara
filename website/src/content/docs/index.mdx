## What Notara includes

<CardGrid stagger>
  <Card title="Markdown notes and directory trees">
    Organize notes in real folders on disk. Includes live preview, formatting toolbar,
    syntax-highlighted code blocks, GitHub-flavored tables, pinned note hoisting,
    starred filters, and atomic file replacement.
  </Card>
  <Card title="Tasks and due-linked reminders">
    Date-based task lists, sub-items, progress tracking, scheduled times, and native desktop
    notifications powered by Rust and system tray background delivery.
  </Card>
  <Card title="Vision boards">
    Drag, resize, recolor, and organize mixed image and text cards for planning,
    inspiration, and reference collections.
  </Card>
  <Card title="Calendar planning">
    Inspect upcoming schedule items, jump back to today, and view selected-day tasks
    and notes in a focused side-by-side workspace.
  </Card>
  <Card title="OpenAI assistant">
    Drafting, summarizing, and image generation using your own OpenAI key. The assistant proposes
    changes with visual diffs so you review every edit before saving.
  </Card>
  <Card title="Local-first storage">
    Desktop builds work directly in a local workspace folder with atomic file writes. Web builds
    connect to local directories via the File System Access API.
  </Card>
</CardGrid>

## A quick orientation

Notara defaults to the **Midnight** theme with a crisp **Pink** accent on flat semantic surfaces.
The application stores notes directly as Markdown files inside your chosen workspace folder,
keeps metadata in a small `.notara` sidecar, and runs background task reminders via native desktop
notifications. Check the [release notes](/reference/releases/) for details on recent updates.
