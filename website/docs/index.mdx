## A quick orientation

Notara defaults to the **Midnight** theme with a crisp **Pink** accent on flat semantic surfaces.
The application stores notes directly as Markdown files inside your chosen workspace folder,
keeps metadata in a small `.notara` sidecar, and runs background task reminders via native desktop
notifications. Check the [release notes](/reference/releases) for details on recent updates.
